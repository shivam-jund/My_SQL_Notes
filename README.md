# My SQL Notes

A collection of personal SQL notes, written while learning and practicing SQL — from basic queries to more advanced concepts like joins, indexing, and query optimization.

## 📚 Contents

Notes are organized into numbered files (`sql_notes_partX.md`) inside this repository, with each file covering a topic or continuing from the previous one. Browse the repo's file list to see all available parts.

## 🎯 Purpose

This repo is mainly for personal revision and reference, but feel free to browse through it if you're also learning SQL. Topics covered include:

- SQL basics (SELECT, WHERE, ORDER BY, etc.)
- Joins and subqueries
- Aggregate functions and grouping
- Indexes and query optimization
- Transactions and constraints
- PostgreSQL-specific concepts and features
